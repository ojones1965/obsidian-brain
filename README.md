# Obsidian Jarvis Vault

A personal knowledge management system organized by PARA principles with AI assistance.

## Structure at a glance

| Folder | Purpose |
|--------|---------|
| **Inbox/Drafts** | AI-generated notes awaiting review and filing |
| **Daily** | Daily notes and reflections |
| **Projects** | Active projects and initiatives |
| **Areas** | Areas of ongoing responsibility |
| **Reference** | Reference material, documentation, research |
| **People** | Contacts, relationships, people notes |
| **Decisions** | Decision records and architectural decisions (ADRs) |
| **Templates** | Templates for common note types |
| **_archive** | Inactive, closed, or historical material |
| **_config** | Vault configuration and rules |
| **SimpleBrain** | Machine-generated research drafts (unreviewed) |

## Quick start

- **Read vault rules**: See `_config/CLAUDE.md`
- **Create a new note**: Add to `Inbox/Drafts/`, then file to the appropriate folder
- **Reference material**: Add to `Reference/`
- **Decision log**: Add to `Decisions/` when making significant choices

## Principles

- **Canonical source**: Markdown files in this vault are the durable source of truth
- **AI-friendly**: Designed for use with Claude/Obsidian
- **Searchable**: Organized to enable quick retrieval
- **Evolving**: Structure grows with your needs—create folders when needed, not in advance

See `_config/CLAUDE.md` for full guidance on retrieval workflow, draft composition, and completion protocol.
