# Vault Agent Rules

This repository is an Obsidian Markdown knowledge vault. Claude Code's fuller rules are in `CLAUDE.md`.

- Search the vault before answering questions that depend on prior documented decisions, projects, configurations, people, or research.
- Cite relative note paths when using vault evidence.
- Distinguish documented facts from inference and recommendations.
- Treat `SimpleBrain/raw/` as unreviewed machine-generated research drafts, not confirmed facts or decisions. Do not modify that folder.
- Default all new AI-generated notes to `00 Inbox/AI Drafts/`.
- Mark new drafts with `source: ai-agent`, `status: draft`, and `tags: [ai-draft]`.
- Do not overwrite, rename, move, delete, archive, merge, or bulk-edit existing notes without explicit approval.
- Do not access or process private, confidential, credential, secret, financial, medical, legal, or personal-data locations unless explicitly requested.
- Never store credentials or secrets in the vault.
- Use valid Obsidian wikilinks when appropriate.
- After writing a draft, state the exact path, summarize it, list related notes, and ask before promotion or modification of existing notes.
